# 77 - ini-tool

Read and edit INI files with Python's `configparser`. Supports section/key
listing, single-value get/set, full dumps, and JSON output.

## Usage

```console
$ cat app.ini
[DEFAULT]
debug = false

[server]
host = localhost
port = 8080

$ ./ini_tool.py list app.ini
DEFAULT
server
$ ./ini_tool.py list app.ini --section server
debug
host
port
$ ./ini_tool.py get app.ini port --section server
8080
$ ./ini_tool.py set app.ini port 9090 --section server
$ ./ini_tool.py set app.ini timeout 30 --section http --create
$ ./ini_tool.py dump app.ini --json
{
  "DEFAULT": {
    "debug": "false"
  },
  "server": {
    "host": "localhost",
    "port": "9090",
    "debug": "false"
  },
  "http": {
    "timeout": "30",
    "debug": "false"
  }
}
```

Behavior:

- option names are case-sensitive (the default lowercasing is disabled)
- interpolation is disabled, so `%` in values is preserved literally
- `DEFAULT` values are inherited by every section, including in `list`,
  `get` and `dump`
- `get` defaults to the `DEFAULT` section; a missing section or key exits `1`
- `set` creates the file if it does not exist; `--create` creates a missing
  section. The file is written in place unless `-o/--output` is given; output is
  regenerated by `configparser`, so comments and original whitespace are not
  preserved

## Commands and options

- `list FILE [--section S] [--json]` - sections, or keys in one section
- `get FILE KEY [--section S] [--json]` - print the raw value
- `set FILE KEY VALUE [--section S] [--create] [-o FILE]` - write a value
- `dump FILE [--json]` - whole file as INI text or nested JSON
- `--self-test` - run round-trip checks in a temporary directory

## Exit codes

- `0` success
- `1` missing file, parse error, unknown section/key, write error
- `2` usage error (unknown command or missing arguments)

## Self-test

```console
$ ./ini_tool.py --self-test
self-test: all checks passed
```
